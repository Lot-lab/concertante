# Concertante

**人間と AI が、共通の入力経路でゲームやシステムを操作し、協力も対戦もできる基盤。**

*A framework that lets humans and AI control games and systems through a shared input layer.*

> **※ 構想段階**

## コンセプト

人間と AI がゲームで協力したり対戦したりするには、AI と人間が同じ条件で操作できる必要があります。Concertante は、人間・AI・スクリプトが同じ入力インターフェースを通る仕組みを目指します。

ゲーム側に手を加えなくても、AI は人間と同じコントローラーを持つ一人のプレイヤーとして参加できます。コントローラー入力で操作できるものであれば、ゲーム以外のシステムも対象にできます。

ただし、AI エージェントはリアルタイムの入力が苦手です。判断に時間がかかり、その長さも一定でないため、ゲームのタイミングに合わせにくいのです。この課題への対処も、設計の中心に置きます。

## 目指す機能

- 人間・AI・スクリプトが共有する入力の共通契約
- タイミングを保った入力実行、および遅延・ジッタの計測
- 複数の入力源(例:人間と AI の同時操作)の統合
- 再現・比較のための記録
- 入力元が応答しなくなったときの入力の自動解除
- 差し替え可能な出力アダプタ(まず OS の仮想入力)
- MCP / SDK / API からの利用

## 名前の由来

*Concertante* は、*concerto*(協奏曲)と同じ語根を持つ言葉です。concerto は「競い合う」から「調和させる」へと意味が移ってきたとされ、競争と協力が同時に成り立つというコンセプトを表しています。
